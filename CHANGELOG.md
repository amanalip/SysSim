# Changelog

SysSim follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic versioning for published releases. User-visible changes accumulate under **Unreleased** and move to a dated version during release preparation. Breaking persistence or engine behavior must identify affected schema/engine versions and migration behavior.

## Unreleased

### Added

- Release governance, production-path validation, build diagnostics, and analytical reference systems.

### Changed

- Documentation now describes privacy, architecture, metrics, contribution, and rollback contracts.

### Fixed

- Scenario citation verification now separates inaccessible clients from broken sources.

## 1.0.0 - 2026-08-31

- Established the education-first architecture playground, deterministic simulator, scenario catalog, persistence, accessibility, and release gates.
