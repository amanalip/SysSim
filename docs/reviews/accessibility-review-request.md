# Qualified accessibility review request

## Reviewer qualification

Use an accessibility specialist or experienced assistive-technology tester who did not implement the interface. Record assistive technology, browser, OS, viewport, zoom, theme, input method, commit, and date.

## WCAG 2.2 AA review matrix

1. Keyboard-only: add/connect/configure, simulation controls, panels, tabs, menus, dialogs, scenario workflow, snapshots, import/export, and recovery from errors.
2. Focus: visible indicator, logical order, no trap, restoration after dialogs, and no obscuring sticky content at 200% zoom.
3. Screen reader: landmarks, headings, control names/states, canvas component descriptions, edge relationships, dialog names, validation errors, status/toast announcements, charts, and simulation state changes.
4. Visual: light/dark contrast, non-text contrast, non-color-only meaning, reflow at 320 CSS pixels, text spacing, and 200% zoom.
5. Motion and input: reduced-motion behavior, touch target sizing, drag alternatives, and cancellation of accidental pointer actions.

Use [WCAG 2.2](https://www.w3.org/TR/WCAG22/) as the normative standard. Automated axe results are supporting evidence and do not replace manual assistive-technology evaluation.
